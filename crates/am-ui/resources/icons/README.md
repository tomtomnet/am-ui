# The application's icons

Everything the window shows comes from here, so that it looks the same under every desktop's icon
theme. `scalable/actions/am-*-symbolic.svg` are symbolic icons: those named after a standard icon
(`am-media-playback-start-symbolic`, ...) are copies from GNOME's Adwaita icon theme (LGPL-3.0 or
CC-BY-SA-3.0); `am-album`, `am-autoplay`, `am-explicit`, `am-lyrics`, `am-queue`, `am-radio` and
`am-sound` are this project's. `scalable/apps/dev.amui.Music.svg` is the application's icon.
